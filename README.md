# Desert Bloom Technologies — Flask + MySQL

The existing website design is kept in `templates/index.html`. The contact form's current JavaScript already posts JSON to `/api/contact`; `app.py` implements that endpoint and stores enquiries in MySQL.

## 1. Requirements
- Python 3.10+
- MySQL Server (or compatible managed MySQL database)

## 2. Create database and a restricted user
Open MySQL Workbench or the MySQL command line and run `schema.sql`.
For local development, create a dedicated database user (change the password):
```sql
CREATE USER 'desert_user'@'localhost' IDENTIFIED BY 'Use-A-Strong-Password';
GRANT SELECT, INSERT, UPDATE ON desert_bloom.* TO 'desert_user'@'localhost';
FLUSH PRIVILEGES;
```
If your Flask server connects from another host, configure the database user/host and network rules appropriately; do not expose MySQL publicly.

## 3. Configure Python
Windows PowerShell, from this folder:
```powershell
py -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```
Edit `.env` with your database details and a long random `FLASK_SECRET_KEY`. Set `ADMIN_PASSWORD_HASH` to a hash generated by:
```powershell
python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('YourStrongPassword'))"
```
Paste the generated hash into `.env`; do not put a plain admin password in the file. The app already loads `.env` automatically. For local development, leave `COOKIE_SECURE=0`; set it to `1` only when serving the site over HTTPS.

## 4. Run
```powershell
python app.py
```
Open http://127.0.0.1:5000. Test the contact form. Visit http://127.0.0.1:5000/admin/login to sign in, then view and update enquiry statuses.

## Notes
- WhatsApp still opens for the customer to review and send the message. Database saving is a separate operation and only happens when the site is served by this Flask backend; opening the HTML directly as a `file://` page will not save to MySQL.
- Do not deploy Flask with debug mode enabled. Use HTTPS, a production WSGI server, CSRF protection for admin forms, rate limiting, backups, and secure environment variables before public launch.
- A local SVG logo is included at `static/logo.svg`, so the logo and favicon do not depend on a missing external image. Replace that SVG with your final brand artwork whenever you are ready.
